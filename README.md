# pkg-qimsdk

This is the debian packaging repository for [qimsdk](https://github.com/qualcomm/qimsdk)

## Branches

- **qli-ci**: The primary branch containing workflow logic in the `.github/` folder, along with boilerplate documentation files such as license, contribution guidelines, and this README.
- **clo/debian/latest**: This branch contains debian packaging rules for Debian forky.
- **clo/debian/trixie**: This branch contains debian packaging rules for Debian trixie.
- **clo/ubuntu/resolute**: This branch contains debian packaging rules for Ubuntu resolute.
